tarea_uno
- Métodos de búsqueda no informada en el Metro CDMX
Este proyecto aplica los algoritmos de búsqueda en Anchura (BFS) y búsqueda en profundidad DFS para encontrar rutas entre estaciones del Metro de la Ciudad de México.

- Descripción del problema
Representación:** Grafo no dirigido donde los nodos son las estaciones y las aristas son las conexiones entre ellas.
Métrica / Costo:** Costo unitario = $1 por tramo entre estaciones contiguas.

- Requisitos
* Python 3.x
* Jupyter Notebook
